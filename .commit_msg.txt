feat: 'creds suggest' subcommand — LLM-assisted password suggestion

Pass free-text password requirements to the local LLM; it returns a
password that meets them. Three-tier cascade:

  1. Parse requirements deterministically (regex: min length, upper,
     lower, digit, special). If any existing shared password already
     fits, return the most complex one.
  2. No fit: ask local LLM (ask_text) to merge/modify existing
     password patterns into a new one satisfying the rules. The LLM
     gets 3-5 sample passwords as style references + explicit rules +
     the original free-text requirements (context regex may have
     missed). LLM is told to MERGE/MODIFY existing patterns, not
     invent something random.
  3. LLM output that fails rules: _repair_password appends missing
     character classes to make it valid.
  4. Total failure: secure secrets-based generator (guaranteed valid).

Usage:
  python apply.py creds suggest "min 12 chars, 1 uppercase, 1 number, 1 symbol"
  python apply.py creds suggest "..." --save   (adds result to shared pool)
